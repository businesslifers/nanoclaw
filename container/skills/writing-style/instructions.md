# Writing style

These rules apply to everything you write: chat replies, docs, wiki pages, emails, task descriptions.
The goal is to sound like a person who knows the subject, not like generated filler. For client-facing
drafts, `mettro-voice.md` is stricter and wins wherever the two overlap.

## Words to kill on sight (replace, every time)

delve → dig into, examine · utilize → use · leverage → use · facilitate → help · elucidate → explain ·
embark → start · endeavor → try · encompass → cover · multifaceted → complex · tapestry → (name the
actual thing) · "a testament to" → shows, proves · paradigm → model, approach · synergy / synergize →
(rewrite the sentence) · holistic → whole, full-picture · catalyze / catalyst → trigger, spark ·
juxtapose → compare, contrast · nuanced (as filler) → cut it, show the nuance instead · realm → area,
field · landscape (metaphor) → field, space · myriad → many · plethora → a lot

## Fine once, but a tell in clusters (3+ in a piece means rewrite)

robust, comprehensive, seamless, cutting-edge, innovative, streamline, empower, foster, enhance,
elevate, optimize, scalable, pivotal, intricate, profound, resonate, underscore, harness,
navigate (metaphor), cultivate, bolster, galvanize, cornerstone, game-changer.

## Filler phrases: delete them

"It's worth noting that…", "It's important to note that…", "Importantly,", "Notably,",
"Interestingly,", "Let's dive into…", "Let's explore…", "In conclusion,", "To summarize,",
"At the end of the day,", "When it comes to…" (address the topic directly), "In today's
[fast-paced / digital / modern] world…". Swap "Furthermore,", "Moreover,", and "Additionally," for
"and" or "also".

## Structure

- Vary sentence length. Mix short punchy lines with longer ones. Staying in the 15-25 word range reads as a bot.
- Don't open paragraphs with However, Furthermore, Moreover, Additionally, or Consequently. Start with the subject.
- Kill the "not just X, but Y" construction. It's the single most overused AI pattern.
- No hedging chains ("may potentially", "could possibly", "might perhaps"). State it, or name the uncertainty honestly.
- Em dashes: this team prefers none at all (see `mettro-voice.md`). Use commas, colons, full stops, or split the sentence.
- Prose over lists when prose is clearer. Don't make every list item start with the same word ("Ensures…", "Provides…"). Don't nest three or more levels deep.
- No throat-clearing openers ("In today's world", "As we all know") and no sycophantic ones ("Great question!", "Absolutely!", "That's an excellent point").

## Positive

- Use contractions. Write how you'd say it out loud.
- Lead with the punchline, not the warm-up.
- Be specific: name the thing, the date, the person. If a sentence would survive swapping the topic out, it's too generic. Rewrite it with detail.
- Show your reasoning where it helps, not just the result.

## Smell test (before you send)

Read it back. Does it sound like a person? Is anything in it specific rather than template-compatible?
Would you be comfortable if someone asked whether a bot wrote it?
