# Concept: AI-Powered SEO/GEO/AEO Service

_Status: Idea stage — April 2026_
_Owner: Raels_

## What It Is

A continuous, agent-powered SEO service that Mettro sells to clients. Not a monthly report — a live, always-on system that monitors, optimises, and builds authority automatically, with a human strategist reviewing and approving outputs.

Covers traditional SEO plus GEO (Generative Engine Optimisation — getting cited by ChatGPT, Perplexity, Google AI Overviews) and AEO (Answer Engine Optimisation — featured snippets, voice, AI answers).

---

## The Product

- Continuous monitoring and optimisation (not monthly)
- On-page SEO handled automatically — meta, headings, schema, internal links, alt text
- GEO/AEO structuring so clients get cited by AI engines
- Automated technical audits with fix flagging
- Backlink prospecting and outreach drafted by agents, reviewed by human
- Local SEO — GBP optimisation, citation building, review monitoring
- Multi-location support — per-location pages, keyword sets, ranking tracking
- Live dashboard instead of a PDF report
- Tiered offering — local / national / AI-visibility focused

---

## The Team

**Agents:**
- Keyword/research agent — gap analysis, competitor monitoring, search intent mapping
- On-page agent — meta, headings, schema, internal links, content optimisation
- GEO/AEO agent — structures content for AI citations, FAQ schema, entity definition
- Local SEO agent — GBP optimisation, NAP consistency, local citation building, review monitoring
- Multi-location agent — location pages, localised keyword sets, per-location ranking tracking
- Technical SEO agent — crawl issues, page speed, Core Web Vitals, broken links, redirects
- Outreach/link building agent — prospect finding, email drafting, follow-up sequences
- Reporting agent — rankings, traffic, conversions, AI visibility, per-location breakdowns

**Humans:**
- SEO strategist — overall direction, client strategy, approvals
- Local SEO specialist — GBP management, review responses, local nuance
- Content reviewer — checks AI-generated content before it goes live
- Account manager — client relationships, reporting calls

---

## What the Human Does

- Reviews agent outputs before anything goes live or gets sent
- Makes judgment calls on strategy direction
- Handles client conversations and reporting calls
- Manages exceptions agents can't resolve
- Estimated: 2–4 hours per client per month at steady state

---

## How It's Sold

- Monthly retainer — same model as paid advertising
- Tiered by scope (local vs national vs competitive niches)
- Results compound over time — strong renewal story
- Can upsell: start on-page only, add backlinks, add GEO layer
- Bundle opportunity: pitch alongside paid ads — "we drive traffic now while building your organic foundation"

**Key sales caveat:** SEO takes 3–6 months to show meaningful movement. Onboarding story needs to set this expectation and show what happens in months 1, 2, 3.

---

## Technical Requirements

**Supported platforms:**
- **WordPress** — best fit, full automation via REST API or plugin. Agent can update meta, headings, schema, internal links, alt text directly
- **Shopify** — on-page basics fully automatable (meta titles, descriptions, alt text, URL slugs). Technical SEO more constrained (no underlying code access without a developer) but on-page + GBP + content optimisation is enough for most clients
- **Other CMS** — audit and recommendations only; implementation quoted separately

**Access required (one-time setup per client):**
- CMS credentials or API access (WordPress/Shopify)
- Google Search Console — rankings, crawl errors
- Google Analytics — traffic and behaviour data
- Google Business Profile API — agent can publish posts, update info, upload photos, pull insights, flag reviews for human response
- Hosting/server access if technical fixes are in scope

**Multi-location clients are the best fit** — manual workload is enormous, so automation value is obvious to them
