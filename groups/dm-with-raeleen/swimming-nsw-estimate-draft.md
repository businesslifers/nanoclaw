## Block 2: Website Design — Artwork Adaptation
**Total: $9,660**

Working from client-supplied JPEG artworks as provided by the previous developer. Mettro will translate these to responsive, production-ready artwork for development. Where source files are not available as editable formats, AI image generation will be used to recreate or adapt imagery where possible.

Please note: AI image generation is not perfect at this stage — results may require some manual refinement — but it gives us a strong and cost-effective starting point when editable originals are unavailable.

Deliverables:
- Homepage
- Mega menu / primary navigation
- Interior / standard content page template
- News listing + news article detail
- Events listing (grid view, list view, monthly calendar view) + event detail
- Resource Hub listing + resource detail
- Sponsor / partners section
- Additional templates TBC at Blueprint stage (estimated 2–3 required)

## Option A: News Article Migration (Drupal → WordPress)
**$5,280 ex GST / $5,808 inc GST**

Swimming NSW has 800+ news articles on the existing Drupal site. Mettro has deep experience with Drupal-to-WordPress migrations — this is a well-understood process for our team.

This option is a bulk import exercise and is outside the base scope.

Deliverables:
- Data mapping (Drupal fields to WordPress post fields)
- Bulk import setup and execution
- Post-import QA and formatting review

Note: Metadata, tags and category assignments will be mapped as best as possible from existing Drupal taxonomy. Any content that requires manual remediation post-import will be flagged.
