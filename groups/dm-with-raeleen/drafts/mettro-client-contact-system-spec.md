# Mettro Client Contact System — Build Spec

## What this is

A ClickUp-based system that ensures every Mettro client is contacted on schedule, with no reliance on anyone remembering. Tasks are created automatically, assigned to the right person, and pre-loaded with context so the team knows what to say.

---

## Structure

Two lists, both inside Operations > CRM Records.

**List 1: Clients** (already exists — update fields only)
The master register. Controls who gets contacted, how often, and by whom.

**List 2: Client Contact Log** (create new inside Operations > CRM Records folder)
The activity history. One task per contact event. Tasks are created automatically by the system.

---

## Step 1 — Update the Clients list

Location: Operations > CRM Records > Clients

### Statuses — no changes needed

The existing statuses are correct. Do not change them:
- lead
- needs review
- with client to review
- client: active
- client: inactive
- archived

Archived clients are excluded from all contact automations.

### New custom fields to add

Add the following fields to the Clients list. All are new — none exist yet.

| Field name | Field type | Options / notes |
|---|---|---|
| Client Service Type | Multi-select | Project / Digital Marketing / Support & Maintenance / Ad Hoc |
| Contact Required | Checkbox | Default: checked. Unchecked = excluded from contact schedule |
| Contact Frequency | Dropdown | Twice weekly / Weekly / Fortnightly / Monthly / Quarterly / Six-monthly |
| Last Contacted | Date | Updated automatically by Automation 3. Set manually for new clients to prime the schedule. |
| Relationship Owner | Person | Who owns this client relationship. Drives task assignment in Automation 1. |
| Relationship Temperature | Dropdown | Good / Quiet / Needs attention / At risk / Opportunity |

### Default contact frequencies by client type

Use this table as a guide when completing the one-off client audit (Step 5).

| Client status + service type | Suggested frequency |
|---|---|
| Lead (hot) | Weekly |
| Lead (warm) | Fortnightly |
| Lead (dormant) | Monthly |
| Active project — standard | Weekly |
| Active project — needs close contact | Twice weekly |
| Digital Marketing retainer | Monthly |
| Support & Maintenance retainer | Monthly |
| Inactive | Quarterly |
| Inactive (lower priority) | Six-monthly |
| Archived | No contact — leave Contact Required unchecked |

## Step 2 — Create the Client Contact Log list

Location: Operations > CRM Records (create a new list inside this folder, alongside the existing Clients list)

Name the list: **Client Contact Log**

### Statuses

Use the same status set as the Production space tasks. Do not create a new set. The statuses the team will use on contact log tasks are:
- **to do** — contact not yet made
- **in progress** — contact started or waiting on a response
- **complete** — contact made and outcome logged

### Task naming format

When Automation 1 creates a task, the name is auto-generated. The format is:

`[Client Name] | [Contact type] | [Month Year]`

Example: `Qld Capital | Monthly check-in | June 2026`

### Custom fields to create

Add the following fields to the Client Contact Log list. These are all new custom fields.

| Field name | Field type | Notes |
|---|---|---|
| Client Name | Text | Human-readable client name. Populated by Automation 1 from the client record. Used for filtering and grouping in list views. |
| CRM Link | Relationship (links to: Clients list) | Machine link to the client record in the Clients list. Used by Automation 3 to update Last Contacted on the correct client. Not for human use — it just needs to exist. |
| Client Service Type | Dropdown | Project / Digital Marketing / Support & Maintenance / Ad Hoc. Copied from client record by Automation 1. |
| Contact Type | Dropdown | Email / Call / Meeting / Report / Other. Filled in manually by the team after contact is made. |

### Built-in ClickUp fields — no setup needed

These already exist on every ClickUp task. Do not create custom fields for these:

| Field | How it is used |
|---|---|
| Task name | Follows the naming format above |
| Assignee | The Contact Owner — set by Automation 1 from the Relationship Owner field |
| Due Date | Set to today by Automation 1 when the task is created |
| Priority | Set to High by Automation 1 so these tasks are visible on dashboards |
| Status | Follows the production status set (to do / in progress / complete) |

### Task description template

Every auto-created Contact Log task includes these 4 sections. Paste this as the default task description when setting up the list (it will be included in every task created by Automation 1):

---

**AI Briefing**
*(Auto-generated by ClickUp Brain — see Automation 2)*
Summarise what has happened since the last logged contact. Include recent tasks, updates, decisions, and open items. If no recent ClickUp activity, review previous Contact Log entries and suggest a contact angle based on the client's status, service type, and past conversations.

**Suggested Talking Points**
*(Auto-generated)*
3–5 practical things to mention or ask.

**Draft Message Starter**
*(Auto-generated)*
A short draft the team can edit before sending.

**Notes and Outcome**
*(Filled in by the team after contact)*
What was said. How the client responded. Anything to action.

## Step 3 — Set up the automations

There are 3 automations in total. Details below.

---

### Automation 1 — Create contact task on schedule (5 separate rules)

**Where to set it up:** CRM Records folder level (Operations > CRM Records). Setting it at folder level means it watches the Clients list and creates tasks in the Contact Log list, both of which are in this folder.

**Purpose:** When a client is due for contact, automatically create a task in the Contact Log, assign it to the right person, and set the priority to High. No human needs to trigger this.

**Why 5 separate rules:** ClickUp cannot calculate "Last Contacted + Contact Frequency = today" in one rule because Contact Frequency is different per client. Instead, create one rule per frequency value:

| Rule | Contact Frequency value | Trigger: Last Contacted is at least... |
|---|---|---|
| 1a | Twice weekly | 3 days ago |
| 1b | Weekly | 7 days ago |
| 1c | Fortnightly | 14 days ago |
| 1d | Monthly | 30 days ago |
| 1e | Quarterly | 90 days ago |
| 1f | Six-monthly | 180 days ago |

Each rule (1a–1f) uses the same When/If/Then structure. Only the trigger date and the Contact Frequency condition change.

**When (trigger)**
Date field "Last Contacted" is at least [X] days ago (use the value from the table above)

**If (conditions)**
- Contact Required = checked
- Contact Frequency = [matching value for this rule]
- Status is not "archived"

**Then (actions)**
1. Create a task in the Client Contact Log list
2. Set task name to: `[client task name] | Check-in | [current month and year]`
3. Set due date to today
4. Set priority to High
5. Assign to: Relationship Owner (from the triggering client record)
6. Set the Client Name field to the client's task name
7. Set the CRM Link field to link to the triggering client record
8. Set the Client Service Type field to the value from the client record
9. Add the 4-section description template (AI Briefing / Talking Points / Draft Message / Notes and Outcome)

**Important:** If a client has no Last Contacted date set, this automation will not fire. Always set Last Contacted when adding a new client (see Step 5 new client checklist).

---

### Automation 2 — Generate AI briefing

**Where to set it up:** Client Contact Log list level

**Purpose:** Pre-load each new contact task with a useful briefing so whoever picks it up knows what to say.

**When (trigger)**
A task is created in the Client Contact Log list

**If (conditions)**
None — runs on every new contact log task

**Then (actions)**
1. Run ClickUp Brain with the AI prompt below
2. Insert the output into the AI Briefing section of the task description

**If ClickUp Brain automation is not available on your plan:** insert the AI prompt as a pinned comment on the task so the assignee can run it manually with one click before contacting the client.

**AI prompt to use:**

> Review the linked client record (via the CRM Link field), the client's Production folder if available, and any previous Contact Log tasks for this client.
>
> Summarise what has happened since the last logged contact. Include completed work, open items, anything waiting on the client, and any upcoming milestones.
>
> If there is no recent activity, review the most relevant previous Contact Log entries and suggest a useful reason to contact this client based on their status and service type.
>
> Provide:
> 1. A short internal briefing (2–4 sentences)
> 2. 3–5 suggested talking points
> 3. A short draft message starter the team can edit
>
> Tone: warm, clear, helpful, direct. No jargon. No fluff.

---

### Automation 3 — Update client record when contact is completed

**Where to set it up:** Client Contact Log list level

**Purpose:** Update the Last Contacted date on the client record as soon as a contact task is marked complete. This re-arms Automation 1 for the next contact cycle.

**This is the most critical automation.** If it fails, the next contact task will not be created on time. Test it thoroughly before launch.

**When (trigger)**
Task status changes to "complete" in the Client Contact Log list

**If (conditions)**
None required

**Then (actions)**
1. Using the CRM Link relationship field, update the Last Contacted date on the linked client record to today
2. Send an in-app notification to the task assignee: "Contact logged for [Client Name]. Please update Relationship Temperature if it has changed."

**How the relationship update works:** ClickUp allows automations to update fields on linked records via a Relationship field. When this automation fires, it follows the CRM Link field to the client record in the Clients list and updates the Last Contacted date there. This is why the CRM Link field must be set correctly in Automation 1.

## Step 4 — Update team dashboards

Each team member already has a ClickUp dashboard. Add a Tasks widget to each person's dashboard with these settings:

- Source: Client Contact Log list
- Filter: Assigned to me + Priority = High + Status is not complete
- Sort: Due date ascending

This widget shows each person their open contact tasks for the week without them needing to navigate anywhere.

---

## Step 5 — New client checklist

Every time a new client folder is created in Production, the person setting it up must also create or update the client record in Operations > CRM Records > Clients.

Required fields to set on every new client record:

- Status (lead / client: active / client: inactive / archived)
- Client Service Type (multi-select)
- Contact Required (check this unless the client should be excluded)
- Contact Frequency (use the default frequency table in Step 1 as a guide)
- Relationship Owner (person responsible)
- Last Contacted (set to today, or to the date of the most recent actual contact — this primes Automation 1)

This step is mandatory. Without Last Contacted being set, Automation 1 will never fire for this client.

---

## Step 6 — One-off client audit

Before launch, go through all 48 existing clients in the Clients list and set the new fields added in Step 1.

For each client, decide:
- What is their current status?
- What service type(s) do they have with Mettro?
- Should Contact Required be checked?
- What is the right contact frequency?
- Who is the Relationship Owner?
- What was the date of the last actual contact? (Set this as Last Contacted to prime the automation)

Work through clients in this priority order:
1. Digital Marketing retainer clients
2. Support & Maintenance retainer clients
3. Active project clients
4. High-value inactive clients
5. Warm leads

---

## Email logging rule

Email integration is not automated yet. Until it is:

If someone else at Mettro may need to know about a client email later, log it manually as a Contact Log task.

Log it if the email includes a project update, a client request, a decision, a delay, feedback, approval, a complaint, a follow-up commitment, or a new opportunity.

---

## The guiding rule

The Clients list decides who needs contact and when.
The Contact Log records what happened.
The system creates the tasks. Humans own the relationships.
