## Blueprint Strategy — $5,500

- Project setup, brief documents, schedule, client material requests
- Project kickoff x 2 team members
- Strategy workshop 1 x 2 team members x 2.5hrs — user journeys, roles, content types, mood board
- Strategy workshop 2 x 2 team members x 2.5hrs — taxonomy, filtering, site structure
- User journey and taxonomy analysis
- Blueprint strategy document
- Client sign-off and approval

**Approx hours:** Strategist 18hrs @ $230 + PM 12hrs @ $190

## Design — $8,500

- Homepage concept design
- Login / authentication screen
- Role-specific journey home (post-login landing)
- Resource list view x 2 layout options
- Resource detail view
- Standard pages x 2
- GreyboxPro brand setup (colour palette, typography, buttons, component review)
- WCAG AA design review across all templates
- Two rounds of design feedback
- Client sign-off and approval

**Approx hours:** Designer 44hrs @ $180 + Strategist 2hrs @ $230

## Development — $23,500

- WordPress new install on WPEngine staging server
- Install and configure core plugins
- Apply GreyboxPro theme and brand
- Navigation and footer setup
- Favicon, breadcrumbs, schema markup
- User roles: Admin / Author / Standard (with custom profile field for journey type)
- Custom post types: Resources (video, PDF, article, tool) and Journeys/Topics
- Taxonomy setup: content type, topic/theme, journey level, status
- Role-aware journey home page (auto-populates content based on user's journey profile)
- Resource list pages with strong taxonomy-based filtering UI
- Resource detail view
- Taxonomy-driven auto content pull onto pages
- Site search (filtered, taxonomy-aware)
- "Last updated" timestamps on all content
- WordPress revision history configuration (full versioning on all content)
- Access logging plugin setup (who accessed what) + automated log pruning configuration
- Content feedback — yes/no relevance rating on each resource
- Gravity Forms — simple user feedback form
- Print CSS
- GTM code
- WCAG AA implementation throughout
- Standard pages build x 2
- Apply sitemap

**Approx hours:** Lead Developer 90hrs @ $250 + PM 6hrs @ $190
