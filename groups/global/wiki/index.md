## Promotion path

Pages from `groups/<group>/wiki/` get promoted here when:
- Two or more groups reference the same entity / concept
- The page is generally useful (not group-specific scratch)
- The operator explicitly asks: *"promote X to global"*

When a page is promoted, the source group keeps a stub linking here so cross-references don't break.
