# Client Profiles

Mettro client knowledge bases. Each file named `[client-slug].md`.

Profiles were originally created and maintained by BriefMate in v1. BriefMate has not yet been ported to v2 — until it is, ClientMate is the source of truth for these profiles. Update them in place when you learn something new about a client (tone, contacts, history, preferences, sensitivities). Load the relevant profile before drafting any client correspondence.
