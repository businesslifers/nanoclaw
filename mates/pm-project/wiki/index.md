# Pm-project — wiki index

The catalog of wiki pages for this mate. Update on every ingestion. This is the primary discovery surface — every entry carries a one-line summary so a reader can decide which pages to load without loading them all.

## Format

```
- [Page title](page-file.md) — one-line summary | tags: tag1, tag2
```

Group entries by memory type. Within a group, order alphabetically by title.
